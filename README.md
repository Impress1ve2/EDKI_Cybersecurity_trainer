# ЄДКІ · Кібербезпека — локальний тренажер

Version 0.01

Версія без завантаження в Deployments або https://impress1ve2.github.io/EDKI_Cybersecurity_trainer/
  
Відкрийте `index.html` подвійним кліком (працює офлайн, без сервера і без інтернету).
Прогрес зберігається в браузері (localStorage); перенос — на сторінці «Статистика» (експорт/імпорт).

Сторінки: Головна · Тренажер за темами · ЄДКІ симулятор (100 питань, таймер) · Статистика.

## Як додати/змінити питання
Дані збираються скриптом `python3 tools/build.py` у `js/questions.js`:
- `tools/source.txt` — файл питань і відповідей;
- `tools/d1.py`, `tools/d2.py` — 3 неправильні варіанти до кожного питання (за номером);
- `tools/n1.py`, `tools/n2.py` — нові питання: (тема, питання, правильна, 3 неправильні).
Скрипт перевіряє структуру і друкує, як часто правильна відповідь найдовша/найкоротша.
Порядок А/Б/В/Г перемішується щоразу під час показу.
